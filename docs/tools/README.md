# Tool guides

Short, practical guides for every utility installed by this repository.
Each page explains what the tool replaces, how it is installed (automatically and manually),
the aliases/shortcuts this setup adds, and the commands you will use every day.

| Tool | Replaces | Guide |
|------|----------|-------|
| [Oh My Posh](https://ohmyposh.dev) | default prompt | [oh-my-posh.md](oh-my-posh.md) |
| [Nushell](https://www.nushell.sh) | bash / PowerShell as the interactive shell | [nushell.md](nushell.md) |
| [eza](https://github.com/eza-community/eza) | `ls`, Terminal-Icons | [eza.md](eza.md) |
| [bat](https://github.com/sharkdp/bat) | `cat`, `less` for code | [bat.md](bat.md) |
| [ripgrep](https://github.com/BurntSushi/ripgrep) | `grep`, `Select-String` | [ripgrep.md](ripgrep.md) |
| [fzf](https://github.com/junegunn/fzf) | PSReadLine history/prediction, `Ctrl+R` | [fzf.md](fzf.md) |
| [zoxide](https://github.com/ajeetdsouza/zoxide) | `cd` | [zoxide.md](zoxide.md) |
| [duf](https://github.com/muesli/duf) | `df` | [duf.md](duf.md) |
| [dust](https://github.com/bootandy/dust) | `du` | [dust.md](dust.md) |
| [GitHub CLI](https://cli.github.com) | the GitHub website for everyday tasks | [gh.md](gh.md) |

All colours follow the Oh My Posh **microverse-power** palette:

| Colour | Hex | Used for |
|--------|-----|----------|
| Background | `#242424` | prompt segments, fzf selection |
| Red | `#f1184c` | prompt user/arrow, keywords, matches, errors |
| Yellow | `#FFBB00` | time, numbers, dates, fzf info |
| Green | `#33DD2D` | path, strings, file paths in `rg`, executables |
| Blue | `#3A86FF` | OS icon, git, directories, functions, headers |
